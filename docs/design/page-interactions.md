## 已确定的行为

- 查词不自动加入学习队列，用户收藏后才加入生词本；保留词形、原句与内容来源。
- 刷新恢复依赖数据库及后端接口，不能用原型的临时内存代替持久化。
- 训练与模考的辅助功能边界不同；模考交卷前不显示答案或解析。
- 错词与错题分别展示，不用一个词汇列表代替题目重做。
- 破坏性内容操作提供确认或撤销；下架不删除历史学习和作答。

## 分阶段交互审查模板

每页记录：入口与返回路径 → 使用角色 → 初始数据 → 主操作 → 提交中状态 → 成功结果 → 空数据 → 可恢复错误 → 中断/刷新 → 手机与键盘操作。

先设计所需的最小页面，不要求把全部原型重新画成低保真和高保真两套。已有原型可直接作为基础；缺少的答题、结果和解析页面在阶段 4 设计中补齐。

2026-10-14用户已确认独立HTML最基础布局，正式Vue已据此调整；业务模块仍按对应阶段设计和验收。原型演示账号、假成绩与 AI 回复不构成产品功能验收。
