## 0. 用户体验原型后的修订（2026-11-02）

以下取代原稿中对应交互描述，其他业务边界保留：

- 学习中可立即加入生词本，收藏与复习状态分别保存；重复加入不重复计数，也不清空打字前缀。
- 手动标记熟练是用户主动免复习，跨词书生效，跳过当前词并从后续自动新学/复习选词中排除；不伪造独立回忆成功，不删除已有记录。首页可管理并恢复；已学词恢复原复习安排，未学词回到待学，不插改原轮次队列。
- 手动熟练与算法阶段、难词标签不同；本书覆盖可包含手动熟练，界面明确口径，不算当日新学/复习通过。服务端数据结构与正式命令将在实施计划中另行设计，此处仅原型。
- 按最新反馈，详情释义删除冗长英文definitionEn，只保留词性和中文；英文词头、音标、固定英文例句及中文翻译、短语与近义词保留。


- 词书切换使用书架选择面板，展示封面、示例词数、已学覆盖和当前选择，不使用裸原生下拉框。
- 新学/复习看词：点认识后查看完整释义，由用户手动点下一词；不受自动切词开关影响。
- 新词跟打：过程只显示英文虚影、音标和发音；不显示中英文释义、字母提示或想不起来按钮。连续完成整轮后，集中显示全部词的中英文释义、例句、短语与近义词。打完一个立即继续，不逐词停详情；出错仍保留失败记录、自动回队再练，不冒充独立回忆。
- 只有复习默写保留字母提示与可选自动切词；辅助完成仍停详情、手动回队。学习计划中的开关明确只管默写。

## 1. 目标与范围

在现有 Vue 3 + TypeScript/Pinia、Java21 + Spring Boot、MySQL/Flyway模块化单体上迭代，保留账号隔离、词典、收藏、文章来源、学习轮次、历史、命令幂等与未知结果重试。

核心目标：一个词汇首页统合新学与复习；学习过程可持续、手机可用；进度含义明确；提示和跟打不冒充独立掌握；页面刷新、退出再登录或切换词书不破坏服务端进度。

本轮设计词汇学习系统，不启动独立AI模块；不自动扩容词库、替换词典来源或收费生成词条资料。根词词缀仅在已有可靠数据时展示。

## 2. 已确认的重要选择

| 问题 | 本方案决定 |
| --- | --- |
| 同一词跨多本词书 | 同一用户、同一词典entry共用掌握状态和复习时间，词书分别展示覆盖进度 |
| 复习范围 | 默认全部来源，允许选择当前词书；不改变选词范围内单词的掌握记录 |
| 新词跟打 | 显示目标虚影，算学习完成，不算独立回忆成功 |
| 复习默写 | 隐藏目标英文；未提示且未出错的完成才算独立通过 |
| 不认识或本轮提示/出错 | 保留详情与本轮失败痕迹，回队再练，不因最后拼对抹掉失败 |
| 自动下一词 | 独立通过或跟打完成可以自动继续，默认开启；不认识/辅助通过停留详情手动继续 |
| 改计划 | 用户全局日目标，不给每本词书独立额度，不删除学习历史 |
| 扩容与词组本 | 独立交付，不能以空菜单或把短语硬塞进单词表代替 |

所有“共用”均限同一登录用户。不同用户的记录完全隔离。

## 5. 词书与掌握状态

### 5.1 共用原则

继续以(user_id, entry_id)唯一标识单词掌握。两个词书中的同一entry不复制调度记录。例：四级学过important后，六级也显示它“已学习过”，但六级总体覆盖仅按六级词条集合计算；不伪造“在六级完成过一次”的历史。

词书统计标记为“本书词汇覆盖进度”，不是“本书学习完成历史”。同一天切换多本书，新增已完成/预留额度共享。已学词可以主动再练，但不算新词、不重复增加累计学习数，也不通过跟打提升掌握阶段。

切换新词来源只影响后续取词。进行中的轮次先暂停保存；不直接改轮次来源、队列或题面。切回原书可以继续保存的原轮次。

### 5.2 复习范围

默认“全部已加入学习的词”；选择“当前词书”时，取属于该词书且已经加入学习、未暂停、已到期的词。不能因切换复习范围把整本未学词自动加入复习。

个人生词范围按personal_enrolled筛选；全局暂停沿用既有语义，不伪装成仅暂停某一本书。多来源同一entry在本轮只出现一个学习项。原先保存的全来源复习轮次继续按原范围执行。

词书下架保留历史、保存轮次和已加入词的全局复习，不再从该版本分配新词。

## 6. 四种学习方式

| 类型 | 首次展示 | 通过条件 | 调度处理 |
| --- | --- | --- | --- |
| 新学看词 | 英文、音标、中文、发音 | 点“学会了”，或“不认识”后再练完成 | 建立首次学习，1天后复习，不称独立掌握 |
| 新学跟打 | 中文/词性、音标、英文虚影、发音 | 完整跟打 | 首次完成，1天后复习，不给独立正确连胜 |
| 复习看词 | 英文、音标、发音；隐藏中文 | 认识/不认识；原有选中文释义方式保留为可选方式 | 无辅助独立通过可晋级；本轮失败后最终通过按失败轮次结算 |
| 复习默写 | 中文/词性、发音和输入进度，隐藏目标英文与会泄题的音标 | 未提示且未出错，拼写完整正确 | 独立通过可晋级；辅助完成需回队再练 |

“看词学过”与“独立回忆通过”是不同结果，统计不得合并为“已掌握”。音频可作为复习模式允许的线索；单独记录是否播放，不宣称严格无提示考试。

### 6.1 稳定的打字交互

底层保留真实输入控件以支持手机软键盘、输入法与无障碍，只隐藏普通边框样式；不使用全局拦截键盘假装输入控件。

目标词排版在切换单词时一次确定。虚影和已输入层使用相同字体、字号、字重、行高和字距；输入过程中不改变宽度或居中位置。长词在手机端按词长一次性选字号或容器滚动，不随每个字母缩放。

输入正确字母保留前缀；错误字母不进入已完成前缀，当前位置短暂反馈，已有正确字母不清空。Backspace删除一个已输入字母；大小写不影响正确性，英文撇号/连字符依现有词形规范统一；没有依据时不接受任意变体拼写。

输入法composition完成后再校验；阻止无效数字/符号插入。允许正常键盘快捷键，不拦截Ctrl/Alt组合；失焦不继续输入。按键长按产生的repeat不能跨越到下一词。整词粘贴不计作独立默写，按辅助完成处理；允许用户继续练习，不能靠禁止粘贴宣称防作弊。

识别式逐字纠错需要客户端持有校验目标；因此该功能是训练，不是防作弊考试。答案来源和最终字符串由服务端校验，不将前端自报“正确”直接作为结果。

### 6.2 下一词与网络状态

任何反馈先由后端确认，再改变学习项。独立通过/新学跟打完成后，展示简短反馈再自动下一词（约350ms，可关闭）；辅助通过和不认识停留完整详情，点继续回队。

自动next本身是独立幂等命令，只有当前item/version/phase仍匹配、页面可见且没有pending时才执行。离页、切词、切账号或隐藏页面时取消自动跳转计时。网络失败保留输入与原requestId，重试确认，不猜测成功后先跳。

### 6.3 提示与本轮再练

“提示一个字母”无确认弹窗。服务端先记录当前尝试已使用辅助，响应揭示位置；仍可继续拼完当前词。想直接看答案时提供“查看释义”，记录未独立完成并进入详情。

使用提示、输错或整词粘贴的这一遍不算独立通过。拼完进入详情，点击继续后该词回当前队列末尾；复习默写后续独立拼对可以完成本轮该项；新学跟打后续无新提示/错误地完整跟打一遍即可完成首次学习，但仍不算独立回忆。两者都保留roundHadFailure/roundHadHint，不延长为无失误晋级结果。

每次队尾再出现是新attempt，同一学习item保持不变。相同attempt的一条HINT命令重放不多加提示次数；不同的有效提示点击可增加揭示位置和次数。上一attempt的迟到输入/提示必须拒绝。

队列只有一个词且反复失败时，不强迫当次刷完：可以暂停保存、返回首页，以后继续。首版沿用ACTIVE/PAUSED/COMPLETED，不新增“结束但未全部完成”状态。暂停项继续保留词条占用、原队列和新词预留额度，不释放后反复分配绕过目标；已经完成的事实不撤销。未完成新词仍从保存轮次继续，已学词仍保持原掌握记录。真正放弃余项、释放占用与额度的机制留待单独设计，不用COMPLETED冒充放弃。

## 7. 计划与日额度

五档预设：悠闲5/30、轻松10/60、标准20/100、进阶35/150、冲刺50/200，另有自定义。数字表示每日新词/复习参考目标。

新用户默认标准；已有用户保留原设置，不批量覆盖成20/100。若自定义数值与预设一致可显示该预设，否则显示“自定义”。数字输入与滑块同步，键盘和屏幕阅读器均可操作。

目标是用户全局设置。新词目标限制当日分配，包含已保存轮次预留的新词；减少目标不撤销已分配项，只停止额外分配。复习目标是参考，不因达到目标禁止积压复习。每轮默认最多20词，目标50/200不意味着一次塞入50/200词。

用户可修改自动下一词、默认练习方式；已有轮次的模式和规则快照不随设置变化。

## 8. 复习规则v2与迁移

继续使用版本化固定调度作为初始策略，不宣称已依据用户表现优化，也不把下面的天数包装成对所有人最优的科学结论。

| 学习阶段 | 独立有效反馈后的间隔 |
| --- | --- |
| 首次学习完成 | 1天 |
| 第一次无失误独立复习 | 3天 |
| 第二次 | 7天 |
| 第三次 | 15天 |
| 第四次 | 30天 |
| 第五次 | 60天 |
| 后续熟练阶段 | 90天，仍需复习 |

默认失败策略：本轮曾不认识、提示或拼写错误，最终独立通过后回到stage1、间隔1天。间隔从本次有效结算时刻按天累计；日目标/连续天数另按上海自然日计算，两者不混用。当前失败即记录失败证据，不等最终完成才持久化；同一轮重试不反复扣等级。对未完成/放弃轮次，词保持可复习，不把全局stage降为0或抹掉“学过”历史。

旧事件、旧due_at与原词条ID不重写；旧保存轮次继续原rule_version。升级前的stage5只代表原30天阶段，不直接变成90天熟练；新v2首次接管时按明确的1/3/7/14→15/30映射，保留原到期时间直到下次有效反馈。新轮次冻结取词范围，每个item冻结自己的rule_version；一轮可包含不同调度版本的旧词，不能只读当前配置数组决定旧轮次结果。

flow_version与rule_version独立：前者决定交互/动作协议，后者决定调度计算。已有v1保存轮次及其词条继续v1规则，且开放轮次对词条的占用阻止另一个v2轮次并发接管；升级期间不改其快照。缺flowVersion的旧客户端可以继续v1交互，但新建轮次由服务器按词条当前规则冻结item调度版本：新词按v2，已迁移的v2词保持v2，即使stage达到6/7也绝不传给只接受0—5的旧调度函数。v1交互的KNOWN等反馈通过服务端规则适配到item调度，不能因此截断60/90天或降成30天。旧客户端未支持HINT等新动作就不提供那些交互，不伪称辅助证据完整；旧flow事件标为LEGACY证据，不回填或冒充新独立通过次数。回滚应用前必须确认目标版本可读取v2数据，否则只回滚界面或关闭v2新建，不运行不兼容旧后端。

涉及stage约束扩展、版本字段和首次完成标记时新增Flyway迁移；不改写V16/V17等已执行迁移。若已有rule_version不足以冻结轮次，补flow版本、item规则版本和事件证据；具体SQL编号在实施时核对最新迁移后确定。

## 9. 状态、难词与统计口径

不要把“学习中/待复习/掌握/难词”设计成一个互斥枚举：

- 学习阶段：未完成首次学习、已完成首次学习、进入较高复习阶段。
- 调度状态：未到期、已到期、已暂停；按当前时间计算。
- 难词：独立标签。默认最近5次有效尝试里错误/辅助达到3次可自动标记，也可手动标记/取消；历史不足5次时展示实际次数，不伪称5次完整窗口。

首页显示“今日新学完成”“今日复习通过”“累计学过”“到期”“连续学习天数”，避免把自报认识或跟打直接叫作已掌握。需要“熟练词”指标时，定义为v2达到60天阶段、至少5次独立通过且最近3次没有辅助/失败；旧数据不足不猜测达标。

统计：用户跨词书去重；词书覆盖按其entry集合与全局学习记录交集；今日新学按首次完成日期去重；今日复习通过按用户/entry/上海日期去重，重试和同日反复练习不增加该指标。另显示“练习次数”时可以累计尝试，但必须单列，不能混入单词数。失败与提示各自计入真实事件；完成轮次与单词通过数分开。

连续天数按上海自然日，至少完成一个学习项才计有效学习日。当天未完成时仍显示截至昨天的连续记录，不因刚过午夜立即归零；没有可靠历史事件的日期不补造。历史趋势延续原事件口径并说明新v2去重指标边界，不暗中重写过去图表。首次完成日期仅在已有可信首次NEW通过事件时回填；没有可靠日期的旧stage>0词仍保留“历史已学”身份，不猜造日期、不重新算新词。

## 10. 单词详情与资料

学习详情复用现有完整词典字段：多词性中文释义、音标、英美浏览器合成发音、固定双语例句、短语、按词义分组近义词、当前文章原句和来源说明。统一展示层，但收藏动作由各入口提供，不能把词书学习伪装成文章来源。

目前固定例句仅覆盖395词头；没有内容显示待补充，不能承诺每词都已齐全。优先完善本轮常见词的数据，不逐次点击临时调用AI凑内容。词根缺数据就不造词根。

已有学习item快照用于判定原题和结果。新词典资料可作为展示补充，不能改变保存轮次的目标拼写和已提交成绩。

## 11. 笔记本与词组迭代

生词本沿用现有收藏、来源、取消收藏和加入学习；词书内收藏使用明确“词书来源”，不能伪造articleId/句段偏移。取消收藏不删除学习记录，暂停学习与取消收藏分开。

词组本是后续独立交付：显示规范英文短语、中文释义、多个来源及原句，可收藏/取消/加入复习。词组实体与词条entry分开，不能让多词短语绕过DictionaryRules单词校验。

短语拼写支持空格、撇号、连字符；按规范表达判定，允许的变体由数据明确列出，不接受模型随意判断。新增短语来源需要服务端校验选区确实存在于本人可访问版本；去重以用户+规范短语为单位，多个来源追加。

短语调度可复用规则和轮次机制的公共逻辑，但本次不贸然把已有word外键全部改成泛型item，设计独立phrase表/关联后再验收。第一版词汇升级不依赖词组本才能上线。

## 12. 数据与接口增量

复用：vocabulary_learning_setting/word/session/item/event/command，vocabulary_wordbook/entry/learning_source，user_word/source，dictionary_entry/form。继续保留(user,entry)唯一掌握记录，不新建每书一份的掌握表，不为词书覆盖进度制造另一套事件。

预期增量（最终DDL在实施计划确定）：

- setting：预设标识或由目标值推导、自动下一词和默认模式偏好；保留已有new_goal/review_goal。
- word：扩展阶段约束、首次完成时间/独立连胜/辅助失败摘要；明确哪些可从事件派生，避免同一事实多个不一致计数源。
- session：flow_version、rule_version、review_scope及来源快照；首版不新增终态，沿用暂停占用/完成释放规则；若未来新增放弃状态，必须单独定义额度与余项去向，并审查全部开放轮次过滤查询。
- item/尝试事件：attempt_no、assisted、roundHadFailure、roundHadHint和持久拼写草稿/输入摘要；同一item可多次attempt，item不复制。输入草稿私有、有长度限制，不逐按键写库。
- event：区分初学完成、独立通过、辅助通过、失败、提示、粘贴与再练；有效命令计次与网络重试分开。
- phrase/phrase_source：仅在词组阶段增加，不复用user_word的单词唯一约束。

现有 /api/v1/vocabulary/learning 下overview/settings/wordbooks/source/session/sessions及feedback/next/state继续保留。按版本扩展DTO，已有客户端或旧会话缺新字段时按v1解释，不改变历史动作含义。

新增或扩展：overview的scope/独立统计；session创建的flowVersion/reviewScope；feedback的HINT、SPELLING_MISTAKE、ASSISTED_COMPLETE等版本化动作；当前尝试编号、辅助标志、揭示数、首次完成与nextCommand状态；私有草稿保存命令（失焦/防抖/退出保存）；完整词典资料展示；趋势/难词筛选。提示/首次错误需先后端确认；每个错误字母不单独发HTTP请求，后续错误次数在当前attempt摘要中补报，服务端边界校验并标注这些是客户端训练输入证据，不当作防作弊考试日志。

新动作不复用或伪造旧KNOWN/SPELLING语义；每条写命令携带requestId、expectedVersion、itemId、attemptNo，并校验当前用户/当前轮次。未知结果保持原UUID查询或重放；旧attempt/旧轮次的延迟命令返回冲突，不自动转交当前词。内容快照、进度修改、队列和事件在同一事务内提交。

## 13. 验收重点与交付顺序

按每阶段完整全栈流程交付，不先堆所有前端再补后端。

A. 首页与计划：紧凑词书、共用掌握语义、全局目标/预设、复习范围、保存轮次入口。先保留当前学习卡，完成真数据取词、设置持久化和归属测试。

B. 学习交互：四种方式、稳定跟打、逐字纠错、完整详情、提示与错误持久化、自动next。每种方式都验证客户端交互与服务端结果，不仅截屏。本阶段可以继续沿用v1天数，但新跟打/辅助完成不能借旧接口提前晋级，辅助标记与独立通过语义必须在本阶段贯通；C再上线完整v2阶段与长期统计。

C. 调度与统计：版本化间隔、历史兼容、失败轮次结算、日去重、熟练/难词、趋势与连续天数。

D. 词组本与词书扩展：逐个有来源数据的词书，以及词组收藏—加入—复习完整闭环。未准备好资料的类别不提前启用。

必须验证：两用户隔离；同词跨书不重复分配/计数；跨书与切回保存；旧轮次冻结；目标降低不丢预留；上海跨日与到期刷新；hint/error后刷新再登录仍保留辅助痕迹；同词重排不复制item；网络未知结果同UUID恢复；自动next与双击/长按只推进一次；页面隐藏不自动跳词；IME/手机/长词无抖动；暂停保存与真正完成区分；取消收藏不删除掌握记录；错误来源和越权短语选区拒绝。
