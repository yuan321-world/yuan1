# 词汇中心查词实施计划

用户已确认首页及学习页的查词弹窗方案，当前实施第一版英文搜索、建议列表、完整词条和加入生词本。

- 复用本地 dictionary_entry、dictionary_form 与现有查词详情。新增有界的精确、词形与前缀检索，每次最多10项。
- 新增词典收藏入口，复用用户锁和收藏记录。V43增加 DICTIONARY 来源类型，收藏不自动加入学习。
- 新增LOOKUP辅助命令，沿用本人轮次、版本、题目与尝试校验及幂等响应。复习默写看到当前词的建议、历史或详情前先保存辅助记录。
- 弹窗复用WordDetails，提供最近查询、键盘选择、英美朗读及收藏。取消过时请求，关闭恢复入口焦点。
- 验证数据库检索与隔离、收藏恢复和幂等、查词辅助，以及桌面/移动端搜索、详情、收藏、输入保留和过时响应。
- 未收录词的第一版空状态说明本地未收录，不自动发起外部翻译。
