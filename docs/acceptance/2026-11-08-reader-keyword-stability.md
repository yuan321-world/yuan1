# 重点词切换侧栏稳定性

用户要求：修复开启/取消重点词时右侧内容跳动，并提出重点词划分建议；本次不擅自实施新的筛词规则。

## 根因与修复

ReadingDetailView在开启重点词、返回焦点或可见性变化时刷新tools以同步当前词书。ReadingRail此前只要busy就将“更多文章”的多个推荐链接替换成“正在加载”，上方卡片收缩，下面词汇面板随之移动；用户在请求未完成时取消高亮仍能看到位移。

慢请求双端Mock复现，修复前桌面词汇面板文档坐标变化184.21875px。修复ReadingRail：已有数据时保留推荐链接，加载/失败/重试在固定高度标题行展示；仅首次无数据时使用原加载/错误块。不改变接口、关键词算法、正文、收藏、阅读进度与生词列表。关键词行key与内部滚动容器保持不变。

## 筛词建议（待用户确认）

现规则为当前词书/个人学习来源与文章完整词及词形的交集，按原文顺序列全部，尚无优先级。建议保留该交集作为候选，排除常用功能词与已标熟练项；同一词条的变形合并；优先未学/待复习及与标题、正文重复出现有关的实义词。默认精选10—15个、最多20个，其他词书匹配词可折叠查看；收藏词继续单列。当前未修改服务端筛选规则，此为产品建议。
