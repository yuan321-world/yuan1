# 背单词升级交互原型

日期：2026-11-02。范围：用户确认设计后要求先制作可交互页面；不是正式功能上线或用户视觉验收。

## 入口与运行

- `http://127.0.0.1:4187/vocabulary-upgrade-preview.html`
- 文件：`docs/prototypes/vocabulary-upgrade-preview.html`、`vocabulary-upgrade.css`、`vocabulary-upgrade.js`、`vocabulary-upgrade-data.js`。
- 静态服务：`D:/python/python.exe -m http.server 4187 --bind 127.0.0.1 --directory "D:/codex/English Hero/docs/prototypes"`。本次以隐藏后台进程运行，日志在忽略目录 `.tool-cache/vocabulary-prototype/`。
- 沿用正式导航入口，外部模块打开4174正式站点；手机提供菜单。生产4174、后端、数据库、原始原型未修改。

## 可体验的内容

1. 新学/复习统一首页，切换四级示例与个人生词示例、切换复习范围；跨词书共享示例掌握记录、分别计算覆盖。
2. 五档日目标与滑块自定义、自动下一词开关；浏览器刷新保留设置。
3. 新学看词/跟打、复习看词/默写；跟打虚影与前缀同宽，错误保留正确前缀；真实输入框支持手机与composition。
4. 提示/不认识/输入错误/粘贴标记辅助；查看固定例句、短语、分义近义词后回队，重新完成才计完成，保留本轮失败证据。
5. 暂停、切换词书、刷新，再恢复原轮次、原词书和输入；后续复习词始终隐藏，详情只揭示当前项。
6. 英美浏览器合成朗读、完成反馈、学习记录和七天趋势；隐藏页面或暂停取消自动切词。

## 演示边界

- 10个现有词典词条的静态摘录，不代表扩库；study/library初始为到期样例，不补造历史。每轮最多3词，便于体验。
- 仅使用隔离的localStorage键 `lingua-vocabulary-prototype-20261102-v1`，重置不影响正式数据；不连接账号、后端或收费服务，不声称跨设备保存。
- 为方便观察完成反馈，原型自动切词等待1.8秒；正式方案约350ms的值仍需实际体验调整。
- 原型只保留一个演示轮次，存在未完成轮次时可切书查看概览，开始新轮次前先完成保存轮次；不演示正式多轮次并发、服务端预留/幂等、网络未知结果重试、规则版本迁移。
- 收藏、文章来源和词条管理保留正式站点入口/说明；词组本、更多词书、难词筛选未在本原型冒充实现。复习看词是自评，不计作独立默写。
- 浏览器语音受系统声音支持影响；自动化未声称验证实际扬声器音色。视觉截图检查不等于用户确认。

## 用户反馈后的修订

- 词书改为带封面、真实示例词数、覆盖与当前状态的原生dialog书架面板，支持Escape和键盘聚焦；不增加虚假词书。
- 修复新学看词被共享auto-next条件自动跳过的问题；看词新学/复习均始终手动下一词，界面移除无效开关。
- 跟打完成一个词立即进入下一个，过程只保留英文虚影/音标/英美朗读，移除中文释义和提示/想不起来；整轮完成集中展示中英文释义及例句等资料。错误仍保留前缀、失败证据与自动回队，保存轮次恢复不丢进度。兼容此前存下的跟打详情状态，恢复时继续原队列，不清空历史。
- 自动下一词设置仅适用复习默写；默写提示及辅助后手动回队保留。
- 先运行针对性用例确认旧版的跟打提示和看词自动跳转复现失败，再修改实现；静态原型不涉及真实API、生产页面或数据库。
- 本轮截图：`*-book-picker.png`、`*-copy.png`、`*-round-complete.png`，同一忽略缓存目录；已实际查看桌面书架、手机书架和新版跟打截图。最终18项桌面/平板/手机Playwright全部通过（退出码0，29.9秒），JS语法检查与文档diff检查退出码0。含书架320宽度无内部横向溢出、辅助回队、看词不自动跳、默写提示保留、跨词书刷新恢复。

## 生词本、手动熟练与释义精简

- 学习题面、详情与跟打整轮回看提供加入生词本/标记熟练。加入时保留正在输入的前缀、回队及复习状态，重复加入不重复；个人示例词书动态更新，浏览器刷新保留。
- 标记熟练立即跳过当前项，对后续新学及复习取词全局生效，跨词书共用。独立免复习标记不删除原掌握/到期历史，不冒充独立通过或新增学习；已覆盖数明确包含手动熟练。完成页另列手动跳过词数。
- 首页“熟练免复习”可恢复：已学词沿用保留的原复习计划；未学词重新可取新词。恢复不篡改原轮次队列与已完成事实。
- 兼容旧演示localStorage，补充notebook/exempt/skipped默认值，不清空已有进度；演示重置同时重置这些演示状态。正式站点收藏和复习数据未访问或修改。
- 按最新截图删去多词性下重复的英文definitionEn，仅保留词性和中文释义；词头/音标/英语例句与其中文翻译保留。
- 先验证旧版缺少操作按钮的两条用例失败，再增加实现；覆盖打字中加入并刷新恢复、动态生词数量、跨范围排除与恢复、跳过整轮不增加完成事件，以及中文释义/双语例句边界。
