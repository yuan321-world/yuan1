## 已实现

- 保留考试家族入口，大学英语合并四级/六级；进入后保留写作、听力、阅读、翻译、整卷栏目。
- 阅读按材料/题组分别显示紧凑行：中文标题优先、英文副标题、来源年月套次、题型题数、练习状态、开始/继续入口；不合并为无关大题组。手机保留简洁卡片。
- 年份、月份直接出现在真题常用筛选；套次、主题保留在更多筛选。搜索、考试、阅读题型、状态、排序、清空、分页、来源隔离及原管理端筛选保留。
- 听力仅按整套设计，无单项训练入口或听力子题型筛选。旧 listeningType/listeningMode URL 清理为整套；阅读条件不带入听力，切回阅读保持原题型能力。
- 听力尚未接入正式服务和内容，明确显示规划与空态；没有构造试听试卷或导入原型占位内容。独立听力HTML原型保留为历史设计演示，本轮不再新造HTML。
- 本轮发现已有两种阅读播放器的 scoped CSS 使用 `:global(parent) descendant` 时，构建输出会错误隐藏整个专注作答页。仅修复四处选择器为完整后代全局选择器，既有专注模式回归恢复；未改作答业务。
