# 词书词表交互原型验收

用户确认先做简单可交互原型，用于讨论整本词书浏览、复习状态及快捷操作，不授权直接修改正式学习模块。

文件：docs/prototypes/wordbook-words-preview.html

## 原型内容

- 暖白柔绿紧凑列表，桌面最大1000宽，320手机自适应；筛选区粘住顶部，正文分批展示。
- 考研24词、四级16词两本明确标注的示例词书，英文/中文搜索、词书/字母排序、隐藏中文。
- 全部、未学习、复习中、已熟练数量；复习中包括尚在流程内的暂停词，二级可筛今天到期/尚未到期/已暂停。分类数量覆盖总词数。
- 星标收藏独立于学习状态；已收藏与难词筛选。
- 点击词头打开统一居中详情：通用音标的UK/US朗读入口、24条原创英中例句、收藏、标熟/恢复原状态、暂停/恢复、难词切换。
- 跨书同词状态共享，保持筛选与浏览位置；浏览/收藏不冒充学过。重置仅重置专用演示状态。
- 返回背单词链接进入原4174正式页面；没有伪造单元划分、学习完成状态或真实词数。

## 隔离范围

独立HTML，不进入Vue生产构建。不调用正式后端，不写账号/数据库，不变更学习或复习算法。不调用百度/DeepSeek。演示存储仅在4187的lingua-wordbook-list-prototype-v1键，正式4174记录不受影响。原始English Learner原型未改。

## 追加反馈：简化复习筛选及书架入口

用户明确删除复习筛选，其他功能保留；建议将“查看”入口放到词书卡片底部，与切换操作各占一半。已在独立原型演示：移除复习下拉及其过滤逻辑，旧本地筛选值清理；书架卡片保留词数/覆盖进度，左“查看词表”右“切换使用”。正在学习的词书右侧禁用并写“当前词书”，左侧查看仍可用。

查看书与学习书通过独立book/studyBook状态区分；查看他书仅更新浏览，顶部提示“仅查看”以及仍在学习的书；切换使用才更新学习来源，保留跨书同词状态。原本地状态自动兼容。书架弹窗height为fit-content并保留视口上限，避免底部大块留白。
