# 写作积累与阅读练习HTML原型

工具栏反馈修正：此前原型遗漏重点词/本篇生词并过度简化Aa。现恢复重点词开关、完整Aa设置演示（字号、行距、字体、对齐、重置）、本篇词汇弹窗。复跑同一脚本，1440/1024/768/390/320px新增工具栏断言及原有写作/练习交互全部退出0。用户要求保留既有功能与入口，已补项目AGENTS约定。仍只做原型，不以静态词汇弹窗宣称已接真实词库。

用户要求先生成简单可交互原型，未批准正式业务实现。本轮新增`docs/prototypes/reading-learning-preview.html`，不改原精读原型、Vue、后端、接口、数据库或服务。

桌面沿用宽正文/窄侧栏，写作摘要独立卡片位于本篇词汇下方；完整句型、词组、例句/中文、使用场景和仿写在原生dialog展示。<=1020px将同一个写作模块移至正文翻译之后并默认折叠，不复制DOM或塞入词汇弹层。阅读题位于正文后，每次一题，选项提交后揭晓解析；三题后显示正确数/正确率。可回顾、重做；标记读完且完成三题后显示模拟打卡，并在本周记录弹窗展示模拟当天状态，未向首页添加周历。

互动包含收藏/取消、个人素材预览、仿写保存/修改/未保存确认、游客登录演示续操作、英中显示切换、字号切换。输入通过textContent/value渲染，不把仿写拼入HTML。身份切换清空私人演示数据，游客答题不迁移为登录正式成绩。所有操作只在页面内存中，刷新清空。

明确限制：文章为节选演示，例句/题目是原型静态示例；答案在本地脚本，不能作为服务端答案保密或鉴权实现。原型“保存”“打卡”不代表真实账号记录，页面顶部/底部及相关结果均作说明。没有网络、付费或AI调用。
