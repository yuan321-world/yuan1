# 背单词使用说明

## 选择来源

登录后进入 `/vocabulary`，点击「切换来源」。书架提供「我的阅读生词」、原四级参考词表，以及考研、六级、四级、高考的乱序版和核心词汇版。两版采用不同词书顺序，重叠单词沿用已有学习记录。

选择来源只保存选择，不会将整本书计入个人已学记录。点击「开始学习」并选择本轮练习方式后分批取词，每批最多20词，受每日新增目标限制。个人阅读生词须先在笔记本或学习页明确加入学习。

学习或复习中点击「退出并保存」，成功后返回首页，可选书、查看进度或进入另一任务。新词按来源分别保存，复习全来源单独保存；再次进入恢复原轮次与练习方式。每个账号同时只有一轮进行中，同词不会重复分配到不同未完成轮次。已保存词书即使下架，仍可在选书面板切回继续。

新建任务额度扣除今天已通过与保存轮次未通过的新词，额度用完可先继续原轮次。跨日旧任务或调低目标不删除已有任务，不把目标解释为绝对每日通过硬上限。

当前释义、队列和反馈由服务端保存；未提交拼写字母保存在本标签页，退出/刷新可恢复，新标签页或存储受限可能需重输。

## 今日学习、生词本与词组本

- **新学看词**：先看英文与中文，确认学会后查看完整词条，由本人点击「下一个」。
- **新学跟打**：照英文虚影输入，过程不显示中文释义、提示字母或想不起来。逐词提交成功后连续下一词，全部完成再集中查看释义、固定双语例句、短语和近义词。
- **复习看词**：先回想中文，再确认认识或想不起来；释义始终手动下一词。
- **复习默写**：根据中文输入英文，题面隐藏词头和音标。输错保留正确前缀；提示与错误由服务端保存，辅助完成后查看详情并回队再练。只有干净通过可以按设置自动下一词。

释义页面不会自动一闪而过。网络失败时使用页面重试入口，不必重新开始一轮。

## 到期复习

新分配词依次按1、3、7、15、30、60、90天安排复习；旧保存轮次仍按原规则完成，不重写原到期时间。本轮出错或使用辅助后最终通过，会从1天重新安排。这里的天是24小时间隔，今日与本周统计按上海自然日计算。

「开始复习」默认涵盖本人全部来源，也可在计划中选当前词书；保存轮次冻结原来源与范围，继续时恢复原轮次。没有到期词时显示下次时间，不提前生成到期记录。复习目标为每日参考目标，积压可分批继续处理。

学习中可随时加入生词本，不清空输入或改变轮次；也可标记熟练，跨词书免复习并跳过当前项，不计作独立学习通过。恢复复习保留原阶段和到期记录。取消生词收藏不会删除学习记录，原有暂停/恢复管理仍保留。

生词本提供搜索、状态筛选、分页、完整词典和多个原文来源。旧`/notebook`地址跳转到生词本。难词自动参考最近5次尝试中至少3次错误或辅助，也可手动标记、取消或恢复自动判断，不影响复习阶段。

词组本支持手动收藏，或从阅读/练习选区、词条短语显式收藏；个人中文释义与备注可编辑，多个来源快照保留。收藏与加入练习分开；看词组回想与按中文默写可以保存/继续，提示或出错回队。词组有独立复习安排、记录和统计，不占今日新单词额度；只有无辅助且本轮未失败的默写才计独立通过。

## 今日进度与统计

首页「今日进度」可查看今日数量与调整目标；收藏加入学习、来源与分页统一在生词本。生词本的「全部学习词」可暂停/恢复包括词书及已取消收藏的学习词。其他保存轮次占用的词优先在原轮次继续。首页本周趋势与「更多学习记录」直接查看，无需跳转统计页。


`/stats` 的「词汇学习」展示累计学习过、成功复习词次、现在到期、完成轮次、本周及近30天学习、连续天数、难词与无辅助独立复习。累计学习过不表示永久掌握；失败重练与同一请求重试不重复计通过。词汇练习不会计入阅读打卡。

## 当前边界

考试词书使用 ECDICT 标签参考数据。乱序版采用可复现的固定顺序，核心版按标签内 BNC 通用语料词频选取前 1,000 词。源数据缺音标时可尝试合成朗读。见[词书来源和收录口径](../content/vocabulary/ecdict-exams-local/NOTICE.md)。
