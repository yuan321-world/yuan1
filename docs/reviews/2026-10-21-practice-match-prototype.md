# 长篇匹配独立原型审查

审查范围：`docs/prototypes/practice-match-preview.html` 与 `docs/design/2026-10-21-practice-match-prototype.md`。仅独立 HTML 原型，不审查或更改正式 Vue/Java/API/数据库与内容。审查方式为逐行检查状态、事件和渲染路径，并对照方案与 Web Interface Guidelines；本审查未重复执行主任务的浏览器尺寸/保存测试，也不将主任务结果写作本人实测。

## 结论

初审的两项 P2 已修复，经指定代码路径复核均可关闭；当前范围未发现剩余 P0–P2 问题。以下保留初审现象和处置记录。修复后浏览器结果由主任务提供：键盘 skip link 保持目录、45题结果定位显示45题与 L 段，file/HTTP 与五种宽度通过；本审查未独立重跑这些测试。

## 已修复发现

1. **P2：从结果定位段落时没有切到被查看的题号，手机保留了错误的题干语境。**
   - 位置：`docs/prototypes/practice-match-preview.html:69`、`:74`、`:53`、`:64`。
   - 结果行只携带 `data-evidence="正确段落"`，点击后只调用 `locate(letter)`，因此 `state.current` 不变。例如当前题为36，交卷后查看45题结果并定位 L 段，原文上方仍显示“当前第36题”及36题陈述。段落虽然定位正确，读者看到的却是另一题；手机题目栏隐藏时尤其难以判断。
   - 建议：结果定位按钮同时携带题号，在定位前更新当前题，再保存并显示原文；答案仍保持锁定。对照方案第15、19行的题干语境与错题定位约定。
   - **处置：已修复并复核。** 当前第70行结果按钮携带 `data-result-q`；第75行先更新 `state.current`，再进入第54行的定位/保存/渲染路径，第65行题干随当前题号更新。提交后的答案禁用逻辑保留。

2. **P2：“跳到主要内容”链接被当成阅读路由，改变了入口页面。**
   - 位置：`docs/prototypes/practice-match-preview.html:15`、`:56`。
   - `href="#main"` 本应跳至当前页面的主内容；但 `view()` 将除空 hash、`#catalog` 和 `#exams` 之外的所有 hash 都判为阅读页。在目录中使用该键盘跳转链接会隐藏目录、显示阅读页，绕过“开始/继续体验”的入口动作。
   - 建议：明确列举阅读路由/阅读锚点，或让 `#main` 保留当前视图；检查目录与阅读页分别使用 skip link 后页面及焦点仍正确。
   - **处置：已修复并复核。** 当前第45、57行显式区分目录与阅读 hash，`#main` 继承当前 `routeView`，不再自行切换至阅读页；第17行主内容增加 `tabindex="-1"` 供焦点定位。
