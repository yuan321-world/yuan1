这份原型怎么体验

  1. 选择大学英语，再进入四级阅读题库。
  2. 组合来源、题型、主题和完成状态筛选，或清空条件。
  3. 开始练习、选择答案；可随时退出并刷新，再继续。
  4. 整组交卷后查看正确率、答案及原文依据。
  5. 故意选错一道题，体验错题本和错题重做。
  6. 在「我的练习」查看原成绩，重做不覆盖旧结果。
